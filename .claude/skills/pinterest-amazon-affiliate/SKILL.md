# 海外 Pinterest × Amazon US アフィリエイト支援

日本在住で英語が苦手なユーザーが、日本的な魅力を武器に海外（特に米国）向けの
ピンを作り、Amazon US アフィリエイトで収益を得られるよう、リサーチから制作・
公開・運用初期設定までを伴走する。ユーザーはノンテクニカルな場合が多い。専門
用語は避け、GitHub 操作などは「クリックする場所」を一段ずつ具体的に案内する。

## 最優先：安全設計（規約リスク回避）

Amazon のアフィリエイトリンクをピンに直接貼るのは規約リスクが高い。したがって
**必ず「ピン → ワンクッションの紹介ページ（LP）→ Amazon US」の導線**を前提に
すべてを設計する。この原則は一度も崩さない。

- ピンのリンク先は常に自作のLP（GitHub Pages 等）にする
- LP には米国 Amazon アソシエイトの正規リンクを置く
- LP 末尾に必ず開示文を入れる:
  `As an Amazon Associate I earn from qualifying purchases.`
- アフィリンクには `rel="nofollow sponsored"` を付ける
- Amazon の商品画像を直接転載しない（規約 NG）。LP の写真はユーザー撮影か、
  AI 生成のイメージ写真を使う（実物確認は Amazon 側でされるので問題ない）
- 「Pinterestの商品タグ機能でAmazonリンクを直貼り」は導線が崩れるので使わない

## 進め方（順番を守る）

ユーザーの負担を最小にするため、一度に全部出さない。次の順で進める。

1. **まず①だけ出す**（売れ型リサーチ、ジャンル5案）
2. ユーザーがジャンルを1つ選んだら、**そのジャンルの②と③を続けて出す**
3. 以降は要望に応じて、画像生成 → リンク埋め込み → 公開 → 運用設定 と進む

各段階の具体は下記。リサーチでは今のトレンドを確認するため、可能なら
WebSearch で「Pinterest trends」「Japan travel boom」等を軽く裏取りする。

## ① 売れ型リサーチ

米国 Pinterest で今伸びている「日本的なジャンル」を5つ提案する。各ジャンルに:

- なぜ今伸びているか（訪日ブーム/季節性/Pinterest公式トレンド等）を一言
- Amazon US で売れそうな関連商品カテゴリを3つ（具体名。例: 和柄ネイルシール、
  障子風フロアランプ、南部鉄器ティーポット）
- 狙う英語検索キーワードを3つ（例: `japandi living room ideas`）

最後に、検索ボリューム × 商品単価 × 「日本在住の説得力」でおすすめを1〜2個
明示し、ユーザーに1つ選んでもらう。

過去に扱った有望ジャンル例（毎回このまま出すのではなく、その時のトレンドで
更新する）: Japandi/和モダンインテリア、日本の台所道具・お茶時間、和柄ネイル・
和風ビューティー、日本文具・ジャーナリング、日本のセルフケア・バスタイム。

## ② ピン画像コンセプト＋英語コピー

選ばれたジャンルで、クリックされるピン画像の指示文（Canva や AI 画像生成用）と
英語キャッチコピーを **3案** 出す。方針:

- コピーはシンプルで、①の検索キーワードを含める
- 「パッと見て意味がわかる」ことを最優先。凝りすぎない
- 効きやすい3つの型を基本にする:
  - **A 情緒型**: 主役1点を美しく（例: 夜に灯る障子ランプ）。感情に刺す
  - **B メイクオーバー/ビフォーアフター型**: 部屋全体や変化。クリック率が高い
  - **C 図鑑/リスト型**: 商品を等間隔に並べ番号やラベルを添える。保存されやすい
    （「◯◯7選」のような番号リスト型もこのバリエーション）
- サイズは縦長 **1000×1500px（2:3）** を指定する

画像生成ツール（Higgsfield 等）が使える場合は、この場で実際に生成してよい。
プロンプトの作り方は `references/image-prompts.md` を参照。

## ③ ワンクッションLP（紹介ページ）

`assets/lp-template.html` を土台に、選ばれたジャンルの3商品を紹介する1枚もの
HTMLを作る。テンプレートの `{{...}}` プレースホルダーを埋めるだけで完成する。

- 見出し・本文は原則 **英語**（読者が米国人のため）。ただしユーザー向けの
  メモやコミットメッセージは日本語
- 「東京在住の私が選んだ」など日本在住の立場を信頼材料として活かす文体
- 各商品カードに短い紹介文（3つ）＋ CTA ボタン「Check Price on Amazon →」
- アフィリンク未取得の段階では `href="#"` にし、ボタン下に
  `【ここにAmazon USのアフィリリンクを貼る】` と明記しておく
- 末尾に Amazon アソシエイト開示文を必ず入れる（安全設計参照）
- トップページ（複数LPへの目次）も同テンプレートの世界観で用意すると、
  サイトに実体が生まれ Amazon 審査にも有利

詳しい埋め方・商品リンク差し替え・写真設定の手順は
`references/lp-workflow.md` を参照。

## 公開（GitHub Pages）

- LP は `docs/` フォルダに置き、GitHub Pages の公開元を `main / docs` にする。
  これでリポジトリ直下の他ファイル（例: 既存のサービスページ）は非公開のまま、
  LP だけを公開できる
- 公開 URL 例: `https://<user>.github.io/<repo>/japanese-tea.html`
- ノンテクニカルなユーザーには「私が変更 → PR → あなたがマージ → 数分後に反映」
  の流れを毎回明示する。PR リンクを渡すことが「マージ待ち」の合図だと伝える
- 変更のたびに作業ブランチを最新 main から作り直す
  （`git fetch origin main && git checkout -B <branch> origin/main`）

## Amazon アソシエイト / Pinterest 初期設定サポート

ユーザーがまだ登録前・設定途中なら、次を案内できる（詳細は
`references/setup-guide.md`）:

- 米国 Amazon アソシエイト登録と税務インタビュー（W-8BEN）。日本在住は
  Individual → 非米国人 → マイナンバーを外国TINとして入力 → 日米租税条約で
  源泉徴収 30%→0%。業務地は「All services performed outside the U.S.」
- 報酬受取: 最初は Amazon ギフトカード、伸びたら Wise/Payoneer の米ドル受取口座
- SiteStripe でのアフィリリンク作成手順
- Pinterest ビジネスアカウント作成・ボード作成・ピン投稿・サイト認証
  （`<meta name="p:domain_verify">` を全ページの `<head>` に追加）
- 運用: 週2〜3枚を継続、成果は2〜4週間後、登録180日以内に3件の売上、
  自分のリンクからは絶対に購入しない
