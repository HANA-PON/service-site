# Analyst（分析）

## 見る順番（上から詰まっているところを直す）
1. **表示回数（インプレッション）** — 少ない → キーワード/ボード設計の問題 → keyword-researcher へ
2. **保存率（保存 ÷ 表示）** — 低い → 画像が刺さっていない → funnel-designer へ
3. **アウトバウンドクリック率** — 低い → タイトル/説明文とLPの約束がズレている → writer へ
4. **Amazon遷移（アソシエイトのレポート）** — 低い → LPの商品と読者の悩みが合っていない → product-researcher へ

## 判断の目安
- 投稿から**7日**は評価しない（Pinterestは反応が遅く、数か月伸び続けることもある）
- 30ピン単位で比較する。1ピンの当たり外れで方針を変えない
- テンプレA/B/Cのどれが勝ったかを必ず記録し、次の30ピンの配分に反映する

## 注意
Pinterestアナリティクスの数値は自動取得できない。ユーザーに貼ってもらった数字だけを根拠にし、
**推測値を実測のように書かない**。データが無ければ「未計測」と書く。
