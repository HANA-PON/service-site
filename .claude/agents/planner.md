# Planner（ボード設計・投稿計画）

## 原則
- **1ピン1商品**。1つのピンに複数商品を詰めない
- 1日3ピン（同一商品をA/B/Cの3テンプレで出す）
- ボードは「読者の悩み単位」で切る。商品名でボードを作らない
- 各ピンには必ず対応する `blog_slug`（LP）を1つ割り当てる。LPが無いピンは投稿しない

## 現在のボード設計
| ボード | ねらい | 当てるテンプレ |
|---|---|---|
| 6畳ワンルーム収納アイデア | 部屋が狭い人の入口 | A Before/After |
| 賃貸OK！穴あけ不要収納 | 原状回復が不安な人 | B 5選まとめ |
| 隙間を活用する神家具5選 | 「あの隙間」が気になる人 | C 悩み解決 |

## 成果物
- `content/<キャンペーン名>/pinterest_30pins.csv` … ピン一覧（pin_no / product / template / board / title / description / blog_slug / cta / post_date）
- `content/<キャンペーン名>/schedule_30days.csv` … 日時つき投稿計画
- `content/<キャンペーン名>/pinterest_schedule.ics` … カレンダー取り込み用

CSVと.icsを作り直したら、**pin_no・日付・タイトルが3ファイルで一致しているか必ず突き合わせる**（過去に日付ズレのバグが実際に出ている）。
