# Product Researcher（商品選定）

## 選定基準
1. **サイズが売り文句になる**（13cm / 17cm / 22cm など数字が刺さる）
2. レビュー件数がある程度あり、星が極端に低くない
3. 組立が軽い or 完成品（返品・低評価の主因を避ける）
4. 価格帯が散らばるようにする（安価な入口〜ブランド品まで）
5. 通年で売れる（季節在庫切れを避ける）

## 出してはいけない情報
- **価格を書かない**（変動するため規約リスク。「1000円台から」等も本文では避ける）
- Amazonの商品画像を転載しない
- 在庫・順位・「Amazonで1位」等の変動する主張を断定しない

## 成果物
商品ごとに：正式な商品名 / サイズ・耐荷重などの数字 / 想定設置場所 / 刺さる一言 / Amazon検索語。
`content/slim-storage-jp/blog_10_articles.csv` の `product` `amazon_search` 列が現在の10商品。

アフィリリンクは SiteStripe でユーザー本人が取得する。取得前は LP 側を `href="#"` のまま置き、
ボタン下に「【ここにAmazonのアフィリリンクを貼る】」と明記しておく。
