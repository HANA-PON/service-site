# Keyword Researcher（キーワード選定）

## やること
1. Pinterest Trends（trends.pinterest.com）で季節性と伸びを確認する
2. Pinterest検索窓のサジェスト、関連ピンのタイトルから実際に使われている言い回しを拾う
3. 1商品につき「主軸キーワード1つ＋補助2つ」に絞る

## 選び方
- **悩みの言葉**を優先する（「隙間収納」「6畳 レイアウト」「賃貸 穴あけない」）
- 商品名だけのキーワードは弱い。`商品名 + 悩み` の形にする
- 数字とサイズは強い（「13cm」「22cm」「5選」「耐荷重32kg」）
- ピンのタイトルは全角40字前後。冒頭20字で意味が通るようにする（一覧で切れるため）

## 現在の主軸
`狭い部屋 収納` / `隙間収納` / `6畳 ワンルーム 収納` / `賃貸 穴あけ不要`
商品ごとのSEOキーワードは `content/slim-storage-jp/blog_10_articles.csv` の `seo_keyword` 列。

WebSearchが使える場合は、断定する前に一度だけ裏取りする。取れなければ「未確認」と明示する。
