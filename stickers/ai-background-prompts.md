# AI生成背景への差し替え手順

現在のステッカー背景はスクリプト描画のイラストです。
AI生成のリッチな背景に差し替えたい場合は、以下の手順で画像を用意してください。

## 手順

1. claude.aiの通常チャット（またはHiggsfieldを使える環境）を開く
2. 下の共通スタイル指定＋各プレートの内容で、正方形（1:1）の画像を9枚生成する
3. できた画像を `stickers/backgrounds/01.png` 〜 `09.png` の名前でこのブランチにアップロードする
   （GitHubのWeb画面で「Add file → Upload files」でOK。またはチャットに添付して渡す）
4. Claude Codeセッションで「backgroundsの画像に差し替えて」と依頼する
   （文字とスクリムを重ねて入稿データに再合成します）

## 共通スタイル指定（全プロンプトの先頭に付ける）

> 静かで物悲しいけれど優しい雰囲気の、日本の絵本風フラットイラスト。
> くすんだ色調（グレー、くすみブルー、生成り、淡い月色の黄色）。
> 余白を大きく取り、文字を重ねる前提で中央〜右側はシンプルに。
> 人物の顔は描かない。文字・ロゴは入れない。正方形。
